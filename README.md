**Продукт**: Кинопоиск


**Сайт:** [https://www.kinopoisk.ru](https://www.kinopoisk.ru/)


Программа Кинопоиск предназначена для пользователей которые хотят посмотреть фильм, мультик или сериал. Найти  информацию о фильме, узнать его рейтинг, просмотреть рецензии от зрителей. 

Как запустить тесты:
В терминале перейти в рабочую папку(cd ...)
Запустить тест и указать путь к папке (pytest --alluredir allure-result)
Посмотреть сформированный тест:
Запустить команду в терминале Allure (allure serve allure-result)
